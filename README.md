# 🎯 Desafio Bootstrap

Este repositório contém um projeto desenvolvido como parte de um desafio para praticar o uso do **Bootstrap**, um dos frameworks CSS mais populares para criação de interfaces responsivas e modernas.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- [Bootstrap 5](https://getbootstrap.com/)

## 📋 Funcionalidades

- ✅ Uso de grid system do Bootstrap
- ✅ Componentes responsivos (navbar, cards, botões, etc.)
- ✅ Layout adaptado para diferentes tamanhos de tela
- ✅ Estilo personalizado com CSS adicional

## 🎓 Aprendizados

Durante o desenvolvimento deste desafio, foram praticados os seguintes conceitos:

- Integração e uso do Bootstrap via CDN
- Utilização do sistema de grid e containers responsivos
- Aplicação de componentes pré-prontos com personalização via CSS
- Organização de código semântico e reutilizável
